# Размещение и обновление

## Сайт — GitHub Pages
Статический сайт из корня ветки `main`: `https://carpiration.github.io/ik-pk-answers/`.
Сборки нет (кроме `data.js` из документов): изменения попадают на сайт через 1–2 минуты после `git push`.

Обновить ответы:
```
python tools/build_data.py
git add -A
git commit -m "Обновить ответы"
git push
```
Проверка: откройте сайт и обновите страницу (Ctrl+F5). В Android-приложении достаточно закрыть и открыть его.

**Откат:** `git revert <коммит>` и `git push` — сайт вернется к предыдущей версии.

## ПК — приложение в отдельном окне
Откройте сайт в Chrome или Edge → значок «Установить» в адресной строке (или меню ⋮ → «Сохранить и поделиться» →
«Установить страницу как приложение»). Появится ярлык на рабочем столе и в меню «Пуск», сайт открывается
отдельным окном без вкладок; окно можно сделать узким — интерфейс под это рассчитан.

## Телефон
- **Android:** APK из раздела Releases (см. ниже) или в Chrome: меню ⋮ → «Добавить на главный экран».
- **iPhone:** Safari → «Поделиться» → «На экран „Домой“».

## Android-приложение
APK — оболочка, открывающая сайт; обновлять его нужно только при изменении `android/`.
```
python android\build.py
```
Нужны Android SDK и JDK 17+ (есть в Android Studio). Перед новой версией увеличьте `VERSION_CODE` в `android/build.py`.
Готовый APK прикладывается к релизу на GitHub (Releases), откуда его удобно скачать на телефон:
```
gh release create v1.1 Otvety-1.1.apk --title "Ответы 1.1" --notes "Что изменилось"
```

Ключ подписи `android/signing/` в репозиторий не попадает (`.gitignore`). Сохраните его копию:
без него обновление APK не встанет поверх установленного.
