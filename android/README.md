# Android-приложение «Ответы»

Оболочка WebView над сайтом `APP_URL` (см. `build.py`): новые ответы и исправления сайта приходят без
переустановки APK. После первого запуска сайт кэшируется и открывается без интернета. Если сайт ни разу
не открывался и сети нет — показывается экран «Нет связи» с кнопкой «Повторить».

Кнопка «Назад» сначала закрывает результаты поиска, затем возвращает к предыдущему экрану, на главной — сворачивает приложение.

## Сборка

Нужны Android SDK (build-tools, platforms/android-35) и JDK 17+ — подходит `jbr` из Android Studio. Gradle не нужен.

```
python android\build.py
```

Результат — `Otvety-<версия>.apk` в корне проекта. Скрипт сам находит SDK (`ANDROID_HOME` или `%LOCALAPPDATA%\Android\Sdk`)
и JDK (`JAVA_HOME` или Android Studio). Если путь к проекту содержит кириллицу, промежуточные файлы собираются
во временной папке (`%TEMP%\otvety-apk-build`) — утилиты SDK не открывают такие пути.

Перед выпуском новой версии увеличьте `VERSION_CODE` (и при желании `VERSION_NAME`) в `build.py`, иначе APK не установится поверх старого.

## Ключ подписи

`signing/release.jks` и `signing/keystore-password.txt` создаются при первой сборке и в репозиторий не попадают.
Храните их копию и никому не передавайте: обновления можно ставить поверх только при подписи тем же ключом.

## Установка

Скачайте APK из раздела Releases на телефоне и откройте его. Android попросит разрешить установку из этого источника.
Или через USB с включенной отладкой: `adb install -r Otvety-1.0.apk`.

## Проверка

`adb logcat -s Otvety` показывает сообщения и ошибки страницы.
