# Ответы ИК и ПК

Статический сайт для быстрого поиска по трем файлам с вопросами и ответами:

| Файл | Содержание |
|---|---|
| ИК вопросы | Новейшая история Узбекистана — 178 вопросов |
| ПК вопросы | Клинические основы специальной педагогики — 52 вопроса |
| ПК Психология | Общая психология — 33 билета по 3 вопроса |

Темная тема, рассчитан в первую очередь на телефон. Работает без сервера и без сети после первого открытия.

## Поиск

- `синапс`, `внимание` — по словам из вопросов сразу во всех файлах; находит и другие формы слова («внимание» → «о внимании», «свойства внимания»). Ниже отдельно показаны вопросы, где слово встречается только в ответе.
- `14` — 14-й вопрос в ИК и ПК и билет 14 по психологии.
- `14.2` или `14 2` — билет 14, вопрос 2.
- `ик 14`, `пк 14`, `билет 14` — номер в одном файле.
- Клавиатура: `/` — фокус в поиск, `↑` `↓` — выбор, `Enter` — переход, `Esc` — закрыть или очистить.

Клик по результату открывает файл на нужном вопросе и выделяет его. Одинаковые вопросы, которые повторяются в исходных списках, показаны один раз с пометкой «также №…».

## Структура

```
index.html, styles.css, app.js   — интерфейс (без библиотек и сборки)
data.js                          — данные, сгенерированы из source/*.docx
source/ik.docx, pk.docx, psy.docx — исходные документы
tools/build_data.py              — генератор data.js (только стандартный Python)
sw.js, manifest.webmanifest       — офлайн-режим и установка на главный экран
```

## Как обновить ответы

1. Замените нужный файл в `source/` (стили документа: `Question` — вопрос «N Текст», обычный абзац — ответ, `Heading1` — «Билет N» или «Источники…»).
2. Пересоберите данные и опубликуйте:

```bash
python tools/build_data.py
git add -A && git commit -m "Обновить ответы" && git push
```

GitHub Pages обновится через 1–2 минуты. Если на телефоне открывается старая версия — обновите страницу (сервис-воркер сначала берет свежие файлы из сети).

## Локальный запуск

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000.
